# متابع فلتر المياه - الإصدار الرابع

## الجديد في هذا الإصدار
- رسومات توضيحية مدمجة لكل مرحلة من مراحل الشمعات، تعمل دون اتصال بالإنترنت ولا تحتاج ملفات صور خارجية.
- إمكانية تصوير الشمعة أو اختيار صورتها من المعرض عند تعديل بطاقة الشمعة.
- ضغط الصورة تلقائيًا قبل حفظها لتقليل المساحة المستخدمة.
- الاحتفاظ بصورة الشمعة القديمة داخل سجلها التاريخي عند تسجيل تغيير جديد.
- الاحتفاظ ببيانات الشراء والتركيب والماركة والموديل والمورد والفني والسعر والضمان وموعد التغيير.
- استمرار عمل بيانات التطبيق محليًا، مع دعم جسر إشعارات Android الموجود في المشروع.

## بناء APK
ارفع محتويات هذا المجلد إلى مستودع GitHub مع الحفاظ على المسارات، ثم شغّل GitHub Actions من workflow باسم Build Water Filter APK. نزّل artifact الناتج بعد نجاح البناء.

## ملاحظات الاختبار
هذا إصدار مصدر يحتاج بناء APK واختباره على هاتف Android فعلي، خصوصًا صلاحيات الإشعارات والتنبيهات الدقيقة وإعادة الجدولة بعد إعادة التشغيل. ملف HTML يمكن فتحه في المتصفح لمعاينة الواجهة والوظائف المحلية، لكن إشعارات Android الأصلية لا تعمل في المتصفح.
